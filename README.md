# 远程键盘

在车机上用 UU 远程看 Mac 的画面，用安卓手机打字：手机网页里输入的内容会直接上屏到 Mac 的当前光标位置。

```
安卓手机浏览器 ──(Tailscale)──► Mac 上的 remote-keyboard ──► 注入到前台 App
车机 UU 远程 ────────────────► 看画面、点鼠标
```

纯 Swift 单文件，没有第三方依赖，也不需要 Node 或 Bun。

## 一次性准备

### 1. 构建

```bash
./build.sh
```

### 2. 安装 Tailscale（让车上的手机连到家里的 Mac）

- Mac：`brew install --cask tailscale`，或者从 App Store 安装，然后登录
- 安卓：从应用商店装 Tailscale，用**同一个账号**登录并保持连接

两边都登录后，Mac 会多出一个 `100.x.x.x` 的地址，手机在任何网络下都能访问它。

### 3. 启动并授权

```bash
./build/remote-keyboard
```

第一次运行时，macOS 会请求“辅助功能”权限。到 **系统设置 → 隐私与安全性 → 辅助功能**，给运行它的终端（Terminal、iTerm、Ghostty 等）打开开关，然后重新运行。

启动后终端会打印 Tailscale 地址和一个二维码。用手机扫码打开，token 会自动保存，以后直接打开页面就行。在 Chrome 菜单里选“添加到主屏幕”，下次一点就能用。

## 使用

- **整句模式**（默认）：用输入法或语音打完一句，点“发送”整句上屏；“发送 + ⏎”会在上屏后再按一次回车。输入法回车键的行为可以在设置里改。
- **实时模式**：打一个字同步一个字，删除也会同步，适合在终端里操作。中文会在选完候选词后上屏。
- **功能键**：Esc、Tab、方向键、⌫、⏎；方向键和 ⌫ 长按会连发。
- **修饰键** ⌘ ⇧ ⌥ ⌃：点一下只作用于下一个按键，快速点两下锁定，再点一下解除。实时模式下可以“点 ⌘ 再打字母”，组合出任意快捷键。
- **快捷键区**：⌘C/V/X/Z/A/S、⌘Tab、⌘空格、⌘W、⌘F、⌃C，可在设置里隐藏。

## 上屏方式

- **直接输入**（默认）：把字符作为键盘事件发给前台 App，不占用剪贴板。如果 Mac 当前是中文输入法，会临时切到英文布局再切回来，避免输入法截获事件。
- **粘贴**：写入剪贴板后按 ⌘V，0.8 秒后恢复原来的剪贴板内容。兼容性最好，某个 App 直接输入不正常时换这个。

## 参数

```text
--port 8765        监听端口
--bind 127.0.0.1   只监听本机（配合 tailscale serve）
--reset-token      重新生成 token（旧链接会失效）
```

token 保存在 `~/.config/remote-keyboard/token`，也可以用环境变量 `RK_TOKEN` 指定。

### 可选：HTTPS + 独立 App 窗口

Chrome 只会把 HTTPS 页面安装成全屏的独立应用。在 Tailscale 后台开启 HTTPS 后执行：

```bash
./build/remote-keyboard --bind 127.0.0.1
tailscale serve --bg 8765
```

手机访问 `https://<mac名>.<tailnet>.ts.net`，在设置里填入 token 即可。

## 安全说明

- 每个请求都要带 token，没有 token 只能打开页面，不能操作 Mac。
- 默认监听所有网卡，同一 Wi-Fi 下也能访问；不想暴露给局域网就用 `--bind` 绑定到 Tailscale 地址或 127.0.0.1。
- 请在停车时使用。
